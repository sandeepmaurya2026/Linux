📋 How to Use

  1. Make sure your Raspberry Pi has an active internet connection.
  2. Open Terminal or connect to the Raspberry Pi using SSH.
  3. Copy the installation command shown above.
  4. Paste the command into the terminal and press Enter.
  5. Enter your sudo password if requested.
  6. Wait for the installation and configuration to finish.

⚙️ What Does the Installer Configure?

XRDP Enables Windows Remote Desktop access to the Raspberry Pi.
VNC Enables VNC support through Raspberry Pi configuration.
RustDesk Installs the specified stable RustDesk version.
Virtual HDMI Configures a 1920×1080 virtual HDMI display.
X11 Configures the system to use X11 instead of Wayland.
Services Enables and starts XRDP and RustDesk automatically.

🔐 RustDesk Access

After installation, RustDesk is configured automatically. The installer also sets the configured RustDesk access password.

Security Notice:
Do not publish a real RustDesk password on a public information page. Use a strong, unique password and consider changing it after installation.

🖥️ After Installation

You can check the services with:

systemctl status xrdp
systemctl status rustdesk

To get the RustDesk ID:

sudo rustdesk --get-id

🔄 Reinstall / Update

Because the installer is hosted on GitHub, you can run the same command again whenever you need to reinstall or update the configuration.
